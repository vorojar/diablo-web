# 战斗决策机制

本轮在现有敌人上实现预警、反击收益和应对差异。具体数值入口为 combat-tactics.js 的 rules，修改后需同步游戏说明与验证。

- Boss：重击预警0.95秒，其他大招0.8秒；蓄力停步锁向，红色边界与读条位于战斗特效上层。触手按多条真实弹道分别显示。预警与pendingSkill共用生命周期，打断后立刻消失。
- 打断：Boss蓄力期间累计技能伤害达到其最大生命4%时取消大招；复活者、重击小怪、突进蓄力遭技能实际命中即可打断。闪避/格挡不计入。
- 破绽：Boss释放后1.1秒、打断后1.2秒，受到伤害增加25%，期间停止移动与新攻击；突进或重击小怪收招0.8秒。
- 复活者：施法0.85秒，优先击杀提示；打断会取消攻击队列里的复活副作用。
- 远程怪：85像素内近战命中可压制0.55秒，取消尚未释放的射击；2.5秒内不会再次被压制。Boss不受该近战压制。
- 骷髅战士：面前120度扇区物理伤害降低35%，替代原随机格挡；侧后方、技能伤害不受此护甲影响，破绽时撤去护甲。地面短弧标明正面。
- 吸血鬼及共享该AI的Boss：突进预警0.65秒，固定路线，不追踪侧移玩家；分步移动检测墙体，结束后可反击。

不增加玩家存档字段。敌人对象池重置读条、破绽与压制计时。自动战斗现有目标/路径逻辑保持，玩家可用手动走位与技能时机主动利用这些机制。
